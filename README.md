# 16-10-Linara
Docker контейнеріндегі микросервисті орналастыру және ресурстарға мониторинг жасау
1. Жұмыстың мақсаты

GitHub Codespaces бұлттық ортасында Python Flask көмегімен веб-микросервис құру, оны Docker контейнеріне орналастыру және CPU мен RAM ресурстарының пайдаланылуын бақылау.

2. Қолданылған технологиялар
GitHub Codespaces
Python 3.9
Flask
psutil
Docker
3. Орындалған жұмыс
GitHub Codespaces ортасы іске қосылды.
app.py, requirements.txt және Dockerfile файлдары жасалды.
docker build -t cloud-monitor-app . командасы арқылы Docker образы құрылды.
docker run -d -p 5000:5000 --name my-cloud-container cloud-monitor-app командасы арқылы контейнер іске қосылды.
docker ps командасымен контейнердің күйі тексерілді.
curl http://localhost:5000 командасы арқылы веб-қосымшаның жауабы тексерілді.
docker stats my-cloud-container командасы арқылы ресурстардың пайдаланылуы бақыланды.

5. Скриншоттар
GitHub Codespaces ортасы және жоба файлдары.
Docker образының сәтті құрылғаны.
docker ps және веб-қосымшаның JSON жауабы.
docker stats my-cloud-container нәтижесі.
6. Қорытынды

Жұмыс барысында бұлттық ортада Flask микросервисі құрылып, Docker контейнерінде іске қосылды. Веб-қосымшаның HTTP арқылы жауап беретіні тексерілді. docker stats командасы арқылы контейнердің CPU және RAM ресурстарын пайдалану деңгейін бақылауға болатыны анықталды.

Бұлттық ортада есептеу ресурстары қашықтағы серверде орналасады және оларға интернет арқылы қол жеткізіледі. Локалды компьютерде қосымша өз құрылғысының процессоры мен жедел жадын пайдаланады. Docker қосымшаны тәуелділіктерімен бірге оқшауланған контейнерде іске қосуға мүмкіндік береді.
